# Anime Black

Anime Black is a full-stack starter project for an anime-focused community app.

## Structure

- `android/` — Android app in Kotlin with Jetpack Compose
- `backend/` — Ktor backend API
- `docker/` — Docker and Postgres setup
- `docs/` — project notes and architecture plan
- `README.md` — overall project overview

## Stack

- Android: Kotlin, Jetpack Compose, Room, Retrofit, Coil
- Backend: Ktor (Kotlin), PostgreSQL, Supabase-ready schema
- Infra: Docker Compose, GitHub Actions-ready
- Notifications: Firebase Cloud Messaging placeholders
